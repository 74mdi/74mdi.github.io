## Lists

Unordered lists can nest and mix marker styles:

+ A top-level item
+ Another item:
  - A nested item
    * A deeper item
    + Mixed markers work too
+ One more top-level item!

Ordered lists preserve their numbering:

1. First item
2. Second item
3. Third item

1. Markdown can auto-number.
1. This is still the second item.

57. Lists can start at a chosen number.
1. And continue from there.

Task lists are supported too:

- [x] Markdown plugins configured
- [ ] Write something lovely

## Code

Inline code: `const koko = "koko"`.

Indented code:

    // Indented code blocks work.
    const greeting = 'koko'
    console.log(greeting)

Fenced code without a language:

```
koko
another line
```

Fenced JavaScript receives syntax highlighting:

```js
var koko = function (value) {
  return value++;
};

console.log(koko(5));
```
